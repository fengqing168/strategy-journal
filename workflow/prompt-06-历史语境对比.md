# Prompt #6: 历史语境对比

## 用途
将当前讲话/声明与该官员/机构最近几次的表述进行逐一对标，识别措辞变化的幅度和方向，判断是"量变"还是"质变"。

## 前置
- Prompt #2（事件关键点提取）— 已有当前事件的 5 维度提取
- 需要提供同一官员/机构前 2-3 次的讲话内容或摘要

## 输入变量
- `{{current_event}}` — 当前事件的完整提取（Prompt #2 输出）
- `{{historical_1}}` — 最近一次（上一次）的事件提取
- `{{historical_2}}` — 再上一次的事件提取（可选）
- `{{speaker_name}}` — 官员/机构名称

## 完整 Prompt

```
# Role
你是一位央行政策历史分析师，专门追踪官员措辞的时间序列变化。

# Input
当前事件（{{speaker_name}}）：
{{current_event}}

历史记录：
- 上次（最近一次）： {{historical_1}}
- 上上次： {{historical_2}}

# Task
逐维度对比本次 vs 上次 vs 上上次。每个维度回答：

1. **措辞变化** — 用词强度是增强还是减弱？
2. **方向偏移** — 偏鹰/偏鸽方向是否发生转变？（可用 → 表示趋势）
3. **幅度评级** — 微小调整(1) / 明显调整(2) / 重大转向(3)
4. **历史模式** — 这次的变化是否延续了前几次的趋势，还是反转？

输出一张对比矩阵。

# Output Format
```json
{
  "speaker": "{{speaker_name}}",
  "timeline": ["上上次日期", "上次日期", "本次日期"],
  "comparisons": [
    {
      "dimension": "利率立场",
      "上上次": "摘要",
      "上次": "摘要",
      "本次": "摘要",
      "trend": "持续偏鹰/持续偏鸽/由鹰转鸽/由鸽转鹰/振荡/不变",
      "magnitude": 1-3,
      "is_reversal": true/false,
      "note": "解读"
    }
    ... (5 dimensions)
  ],
  "overall_trend": "",
  "significance": "常规变动/值得注意/重大信号"
}
```

# Rules
- 如果 3 次数据点显示一致趋势（如 连续3次偏鹰），标注 `significance: "重大信号"`
- 如果本次比前两次出现了方向性反转，即便幅度小也标注 `is_reversal: true`
- 如果只有 2 次数据（缺上上次），只做本次 vs 上次的对比，并在 note 中说明数据不足
```

## 自定义说明
- 建议为每个经常关注的官员（如 Powell、Hammack、Waller 等）维护一个历史话语档案，每次新讲话后更新，方便下次对比
- 历史记录可以存储在简单的 JSON 文件中，随流程自动读入
