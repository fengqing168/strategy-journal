# Prompt #7: 矛盾与异常检测

## 用途
检查 AI 前面的分析中是否存在内部矛盾、逻辑不一致或数据冲突。这是整个工作流的"质检环节"——在进入人工判断之前，先让 AI 自己审查自己的输出。

## 前置
- Prompt #4（鹰鸽打分）
- Prompt #5（多维影响评估）
- Prompt #6（历史语境对比）
需要这三个 Prompt 的完整输出。

## 输入变量
- `{{scoring}}` — Prompt #4 输出
- `{{pathway}}` — Prompt #5 输出
- `{{history}}` — Prompt #6 输出
- `{{original_text}}` — 事件原始文本（用于回查引用准确性）

## 完整 Prompt

```
# Role
你是分析质检员。你的唯一职责是找出前面 AI 分析中的矛盾、不一致和可疑结论。

# Input
事件原始文本：
{{original_text}}

鹰鸽打分（Prompt #4）：
{{scoring}}

传导路径分析（Prompt #5）：
{{pathway}}

历史语境对比（Prompt #6）：
{{history}}

# Task
逐一检查以下 5 类问题：

**第 1 类：内部矛盾**
- 5 个维度的打分之间是否有逻辑矛盾？
- 例如：打分显示"通胀措辞 +4（偏鹰）"但"风险提及 -2（偏鸽）"，这两个判断是否能在原文中共存？还是有一个评错了？

**第 2 类：路径矛盾**
- Prompt #5 的 4 条传导路径之间是否有矛盾？
- 例如：利率预期路径判断利空金价，但风险情绪路径同时判断利好金价——这是合理对冲还是分析缺陷？

**第 3 类：引用漂移**
- Prompt #4 的 `key_evidence` 中的引用是否真的来自原文？
- 是否有"AI 编造的引用"？（对照 {{original_text}} 核对）

**第 4 类：历史偏差**
- Prompt #6 的历史对比是否有统计意义上的异常？
- 如果本次偏移幅度（magnitude）是历史上该官员从未出现过的，标注为"异常偏移"

**第 5 类：置信度虚高**
- 如果某个结论用了"明确/显然/毫无疑问"等绝对化措辞，但支撑数据薄弱，标注"过度自信"

# Output Format
```json
{
  "check_id": "{{event_id}}",
  "issues_found": [
    {
      "type": "内部矛盾/路径矛盾/引用漂移/历史偏差/过度自信",
      "severity": "严重/中等/轻微",
      "description": "",
      "affected_prompts": ["Prompt #X", "Prompt #Y"],
      "suggested_fix": ""
    }
  ],
  "clean": true/false,
  "summary": ""
}
```

# Rules
- 宁错杀不放过。只要有哪怕轻微的怀疑，都写进去并标注 severity 为"轻微"
- 如果没有任何问题，`clean: true`
- 每一个 issue 必须给出具体的 affected 数据点和 suggested_fix
```

## 自定义说明
- 这个 Prompt 建议在每次运行完 #4-#6 后都跑一遍。发现的问题可以返回修正，或标注后进入人工裁决阶段
- 如果时间紧张，至少检查"内部矛盾"(第1类)和"引用漂移"(第3类)——这两类是最致命的
