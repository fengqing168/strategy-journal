# Prompt #13: 技术面分析

## 用途
基于价格数据和关键技术水平，分析 XAUUSD 当前趋势结构、支撑阻力位和潜在突破方向。不依赖图表——输入数值描述即可。

## 前置
- Prompt #8（AI 初判）— 已有基本面方向判断
- 需要提供当前技术面数据

## 输入变量
- `{{current_price}}` — 当前价格
- `{{timeframe}}` — 分析周期（4H / 日线 / 周线）
- `{{recent_high}}` — 近期高点
- `{{recent_low}}` — 近期低点
- `{{ma_short}}` — 短期均线（如 20EMA）
- `{{ma_long}}` — 长期均线（如 50SMA / 200SMA）
- `{{rsi}}` — RSI 数值
- `{{volume_note}}` — 成交量描述（放大/萎缩/正常）
- `{{pattern_notes}}` — 观察到的形态（头肩/双底/三角/无明显形态）
- `{{price_structure}}` — 价格结构描述（更高的高点/更低的高点等）

## 完整 Prompt

```
# Role
你是 XAUUSD 技术分析师。基于以下数据，对黄金的当前技术结构做出判断。

# Context
当前价格：{{current_price}}
分析周期：{{timeframe}}
基本面偏向（来自之前分析）：{{output_8}}

# Input — 技术水平数据
| 指标 | 数值 |
|------|------|
| 近期高点 | {{recent_high}} |
| 近期低点 | {{recent_low}} |
| 短期均线 | {{ma_short}} |
| 长期均线 | {{ma_long}} |
| RSI(14) | {{rsi}} |
| 成交量 | {{volume_note}} |
| 形态 | {{pattern_notes}} |
| 价格结构 | {{price_structure}} |

# Task
1. **趋势判断**
   - 多头趋势还是空头趋势？震荡？
   - 趋势的强弱评级（1-5，5=极强趋势）

2. **关键价位**
   - 最重要的 2 个阻力位（带价格和理由）
   - 最重要的 2 个支撑位（带价格和理由）
   - 当前价格离哪个关键价位最近？有多近？

3. **形态分析**
   - 是否形成可辨识的技术形态？
   - 该形态的目标位在哪里？

4. **RSI 信号**
   - RSI 当前在什么区间？（超买 >70 / 超卖 <30 / 中性 30-70）
   - RSI 是正在朝哪个方向移动？
   - RSI 是否存在背离？（价格新高但 RSI 没新高 / 价格新低但 RSI 没新低）

5. **均线信号**
   - 短期均线在长期均线之上还是之下？（金叉/死叉）
   - 价格在均线之上还是之下？
   - 均线是正在发散还是收敛？

6. **技术面结论**
   - 单纯从技术面看：偏多 / 偏空 / 中性
   - 置信度（1-10）

7. **与基本面的一致/矛盾**
   - 技术面的判断和基本面的判断是否一致？
   - 如果不一致，哪个信号更可能在当前周期主导？

# Output Format
```

## 自定义说明
- 如果你没有完整的均线/RSI 数据，填入"无数据"，AI 会跳过对应分析维度
- 价格结构描述举例："连续 3 根 4H 阳线，高点越来越高" 或 "前高 $4300 测试三次未突破"
