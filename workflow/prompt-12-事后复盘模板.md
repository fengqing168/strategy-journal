# Prompt #12: 事后复盘模板

## 用途
在交易结果出来后（无论盈亏），对从 Prompt #1 到 #11 的整个流程进行系统性复盘。回答一个核心问题：「如果再来一次，在哪一步会做出不同决定？」

## 前置
- 本次事件的完整工作流输出（Prompt #1-#11）
- 交易的实际结果（盈亏、点位、持有时间）
- 后续出现的新信息（复盘时已知、决策时未知的数据）

## 输入变量
- `{{workflow_output}}` — 本次完整分析链（#1-#11）
- `{{trade_result}}` — 实际交易结果：方向、盈亏、入场/出场点位、持仓时间
- `{{hindsight}}` — 复盘时已知的后续信息（如：NFP 实际数据出来后的走势、后续事件）

## 完整 Prompt

```
# Role
你是交易复盘分析师。不评判对错——只找出系统性问题。

# Input
本次工作流完整输出：{{workflow_output}}
实际交易结果：{{trade_result}}
后续已知信息：{{hindsight}}

# Task
按以下框架进行事后复盘：

**1. 信号质量审计**
- Prompt #4（鹰鸽打分）的打分是否事后看准确？
- Prompt #5（传导路径）的路径判断是否合理？
- Prompt #8（AI 初判）的结论是否正确？
- Prompt #9（人工判断）的结论是否正确？

**2. 决策质量审计**
- Prompt #11（决策矩阵）的加权得分是否合理？
- 是否存在"规则说不行但我执意做了"？
- 是否存在"规则说行但我没做"？

**3. 信息缺口分析**
- 决策时缺少什么信息？如果当时有，判断会不同吗？
- 哪个前置 Prompt 遗漏了关键信息？

**4. 流程改进建议**
- 是否有哪个 Prompt 需要调整？（措辞、权重、顺序）
- 是否有新的信号需要加入？
- 是否有需要移除/简化的步骤？

**5. 知识更新**
- 这次学到了什么？
- 有没有发现新的规律或相关关系？

# Output Format
```json
{
  "trade_id": "{{event_id}}",
  "outcome": {
    "result": "盈利/亏损/未触发",
    "pnl": X,
    "duration": "",
    "entry": X,
    "exit": X,
    "direction": ""
  },
  "signal_audit": {
    "prompt4_accuracy": "事后看准确/不准确/无法判断",
    "prompt5_accuracy": "",
    "prompt8_correct": true/false,
    "prompt9_correct": true/false
  },
  "decision_audit": {
    "rule_followed": true/false,
    "overrides": ["任何人工覆盖规则的行为"]
  },
  "information_gaps": ["决策时不知道但事后知道的关键信息"],
  "process_improvements": ["对工作流的具体改进建议"],
  "lessons": ["教训或新发现"],
  "archive_tag": ["标签，方便未来检索同类复盘"]
}
```

# Rules
- 不要写"我觉得..."——只写基于输出的客观分析
- 如果某个 Prompt 这次没用到，标注"未运行"
- lessons 必须是可行动的（"以后应该在 XX 条件出现时更谨慎"），不能是模糊的（"以后要更小心"）
```

## 自定义说明
- 建议每个交易事件都运行一遍 #12，保存在单独的文件中。积累 10-20 篇复盘后，你会看到清晰的模式（如：某些 Prompt 总是准、某些维度总是偏）
- 复盘数据直接喂给置信度规则表做历史准确率的更新
