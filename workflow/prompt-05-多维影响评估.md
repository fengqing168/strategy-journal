# Prompt #5: 多维影响评估

## 用途
将鹰鸽打分映射到对 XAUUSD 的 4 条影响路径——利率预期、美元强弱、风险情绪、通胀预期——量化每个路径的冲击方向和强度。

## 前置
- Prompt #4（鹰鸽打分）— 已有 5 维度得分

## 输入变量
- `{{scores}}` — Prompt #4 的 JSON 输出（含 5 维度得分和裁决）
- `{{current_price}}` — 当前 XAUUSD 价格
- `{{current_dxy}}` — 当前美元指数（或主要货币对水平）

## 完整 Prompt

```
# Role
你是一位宏观策略分析师，擅长将央行政策信号翻译为资产价格传导路径。

# Context
当前 XAUUSD：{{current_price}}
当前美元指数：{{current_dxy}}
黄金对以下因素敏感：实际利率（反向）、美元（反向）、避险需求（正向）、通胀预期（正向）

# Input
某官员/会议的鹰鸽评分（来自 Prompt #4）：

{{scores}}

# Task
将 5 维度得分映射到 4 条传导路径，每条路径的输出包含：

1. **利率预期路径**
   - 鹰派发言 → 实际利率上升预期 ↑ → 金价压力 ↓
   - 鸽派发言 → 实际利率下降预期 ↓ → 金价支撑 ↑

2. **美元强弱路径**
   - 鹰派发言 → 利差扩大预期 → 美元走强 → 金价压力 ↓
   - 鸽派发言 → 利差收窄预期 → 美元走弱 → 金价支撑 ↑

3. **风险情绪路径**
   - 如果官员强调"不确定性/地缘风险" → 避险需求 ↑ → 金价支撑 ↑
   - 如果官员强调"经济韧性/软着陆" → 避险需求 ↓ → 金价压力 ↓

4. **通胀预期路径**
   - 如果官员对通胀的措辞比市场预期更强硬 → 表明通胀粘性超预期 → 黄金作为抗通胀资产获益 ↑
   - 如果官员淡化通胀 → 通胀预期回落 → 金价支撑减弱 ↓

每条路径打分：-3 到 +3（正 = 对金价利好，负 = 对金价利空）

# Output Format
```json
{
  "event_id": "{{event_id}}",
  "pathways": {
    "利率预期": {"score": X, "rationale": "", "confidence": "高/中/低"},
    "美元强弱": {"score": X, "rationale": "", "confidence": "高/中/低"},
    "风险情绪": {"score": X, "rationale": "", "confidence": "高/中/低"},
    "通胀预期": {"score": X, "rationale": "", "confidence": "高/中/低"}
  },
  "composite": X,
  "composite_direction": "看涨/中性偏涨/中性/中性偏跌/看跌",
  "dominant_pathway": "",
  "note": ""
}
```

# Rules
- composite = 4 条路径得分之和（-12 ~ +12）
- 如果任意一条路径的 confidence 为"低"，composite note 中必须标注不确定性来源
- 如果出现"鹰鸽信号矛盾"（如利率偏鹰但避险偏鸽），note 中说明哪个路径更可能主导
```

## 自定义说明
- 这个 Prompt 可以被其他资产类别的分析复用（替换 XAUUSD → 原油/股指/国债），只需调整 Context 中的敏感性描述
