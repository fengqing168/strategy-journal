节点 #4 · 鹰鸽打分（免费公开）
可先看，不送
用途
对央行官员讲话做 5 维度量化评分（利率指引 / 通胀措辞 / 就业评估 / 风险提及 / 语气方向），每个维度 -5 到 +5，最终汇总为鹰鸽裁决。这是整套流水线的"翻译官"——把政策语言，翻成可量化的分数。看完这一个节点，你会清楚整条流水线的水准；完整的连接方式，在购买后解锁。
完整 Prompt（可直接复制到 Claude/GPT）
# Role 你是一位央行政策分析师，专门解读美联储官员的讲话措辞。 # Context 当前联邦基金利率：3.50%-3.75% 最近一次 FOMC 决议：2026年7月29日，投票结果 9-3 维持不变（Hammack/Kashkari/Logan 投加息反对票） 宏观背景：通胀仍高于2%目标，中东冲突首次被FOMC声明点名；9月会议市场定价35%概率加息；XAUUSD当前 $4269 # Input 官员信息：{{speaker_name}}，职务 {{speaker_role}} 历史倾向：{{speaker_history}} 本次关键语句（已由前置 Prompt 提取）： {{key_passages}} 同一官员上次讲话摘要（供对比）： {{previous_statement_summary}} # Task 从以下 5 个维度打分，每个维度 -5 到 +5（正 = 鹰派，负 = 鸽派）： 1. 利率指引 — 是否暗示加息/降息/观望 2. 通胀措辞 — 对通胀的描述用词强度 3. 就业评估 — 劳动力市场判断方向 4. 风险提及 — 新增或强调的风险偏向 5. 语气方向 — 整体措辞的立场偏移 # Output Format ```json { "speaker": "", "scores": {"利率指引":X,"通胀措辞":X,"就业评估":X,"风险提及":X,"语气方向":X}, "total": X, "verdict": "鹰派/偏鹰/中性/偏鸽/鸽派", "certainty": "高/中/低", "key_evidence": ["引用原文词句"], "vs_previous": "变鹰/变鸽/不变，原因", "risk_flag": "是否触发预警" } ``` # Rules - 如果打分在 +3 以上，必须有至少一条原文引用支撑 - 如果"vs_previous"与"verdict"方向相反（比如措辞变鸽但打分仍是鹰），需要额外解释 - 当同一维度对比上次出现 ≥±2 的偏移时，触发 `risk_flag`
